**Tarea Aspectos - Diseño de Software**

**Sección A**

objetos. Además, ilustre el diseño e implementación del patrón de diseño Singleton utilizando el paradigma
orientado a objetos. 

**Sección B**

puramente orientada a objetos.

**Sección C**
